# DIANA Contabilidad: versiones

Este repositorio sólo publica los instaladores firmados de DIANA para su actualización automática.
No contiene código fuente ni datos.

Cada release incluye el instalador, `latest.json` (versión, tamaño y SHA-256) y `latest.json.sig` (firma Ed25519).
DIANA verifica la firma con su llave pública antes de instalar cualquier cosa.
